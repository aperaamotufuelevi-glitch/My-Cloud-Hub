My Cloud Server

Not connected. Follow the setup steps below, then add the server address and password in Settings.
Setup steps (one time)
  1. Create the database.

    In the Cloudflare dashboard open Storage & databases → D1 SQL database → Create. Name it my-cloud-db. Open it and copy its Database ID.

  2. Create the file storage.

    Open Storage & databases → R2 object storage → Create bucket. Name it my-cloud-files. Cloudflare may ask you to add a payment method first; the free plan covers 10 GB.

  3. Fill these in.
  4. Send the server code to GitHub.

    Needs GitHub connected in Settings. This creates a private repository and puts the server code in it. Use the same button later to install updates; Cloudflare redeploys automatically.

  5. Connect it in Cloudflare.

    Open Workers & Pages → Create application → GitHub (import a repository). Pick the repository from step 4 and choose Save and Deploy. Keep the project name the same as the server name in step 3.

  6. Add your secrets.

    Open the new Worker → Settings → Variables and Secrets → Add, type Secret. Add HUB_PASSWORD (use the generated one below), ANTHROPIC_API_KEY (your one Anthropic key), and if you want email through the server, EMAILJS_PUBLIC_KEY and EMAILJS_PRIVATE_KEY.

  7. Connect the hub.

    Copy the Worker address (it looks like https://my-cloud-server.yourname.workers.dev) into Settings → My Cloud Server, then Save & test.

GitHub connection

Create a fine-grained token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Give it access to All repositories with these repository permissions: Contents (read and write), Pages (read and write), Administration (read and write, needed to create repos). The token stays in this browser only and is never included in exports or sync.
