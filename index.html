Server setup (one time, already done)
  1. Create the database.

    In the Cloudflare dashboard open Storage & databases → D1 SQL database → Create. Name it my-cloud-db. Open it and copy its Database ID.

  2. Create the file storage.

    Open Storage & databases → R2 object storage → Create bucket. Name it my-cloud-files.

  3. Fill these in.
  4. Send the server code to GitHub.

    Needs GitHub connected below. Also installs this hub on the server. Cloudflare redeploys in about a minute.

  5. Connect it in Cloudflare.

    Workers & Pages → Create application → GitHub. Pick the repository from step 4 and deploy. Keep the project name the same as the server name.

  6. Add your secrets.

    Worker → Settings → Variables and Secrets → Add, type Secret: HUB_PASSWORD, and optionally ANTHROPIC_API_KEY, EMAILJS_PUBLIC_KEY, EMAILJS_PRIVATE_KEY.

  7. Connect the hub.

    Put the Worker address and password in Connection to My Cloud Server above.

GitHub connection

Only needed for GitHub Pages and for installing server updates.
